1. Identification de l'opération

Renseignez le nom, l’adresse et le code postal tels qu’indiqués dans le contrat de certification.

2. Comment renseigner les données financières ?

Deux méthodes sont possibles : PDF ou Excel / tableau copié-collé. Dans les deux cas, l’objectif est le même : identifier le montant HT, le lot / poste, puis valider la donnée pour l’ajouter au récapitulatif financier.

📄Mode PDF

Déposez un ou plusieurs PDF, affichez la page utile, puis utilisez le panneau de droite pour surligner le montant et le lot directement dans le document.

  1. 1Glissez le PDF dans la zone de dépôt, puis choisissez le document affiché et la page à analyser.
  2. 2Pour travailler plus confortablement, utilisez ⛶ Plein écran. Le PDF occupe alors presque tout l’écran et reste ajusté automatiquement à la largeur disponible.
  3. 3Cliquez sur 1. Valeur HT, puis directement sur le montant. Les nombres sont découpés en zones fines pour éviter de sélectionner toute la ligne. Vous pouvez aussi maintenir le clic et glisser sur plusieurs fragments.
  4. 4Cliquez sur 2. N° / nom du lot, puis sur le libellé. Pour un libellé composé de plusieurs mots, maintenez le clic et glissez sur les mots à conserver, ou utilisez Maj / Ctrl / Cmd pour compléter la sélection.
  5. 5Choisissez la catégorie financière, ajoutez un commentaire si nécessaire, puis cliquez sur Ajouter la donnée financière.
